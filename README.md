# 📘 Revisão DP-900 – Microsoft Azure Data Fundamentals

Este repositório reúne **materiais de revisão e anotações de estudo em português** para a certificação **[Microsoft Azure Data Fundamentals (DP-900)](https://learn.microsoft.com/en-us/credentials/certifications/azure-data-fundamentals/?practice-assessment-type=certification)**.  
O conteúdo serve como **complemento à trilha oficial e gratuita da Microsoft Learn**, ideal para quem está se preparando para o exame e quer reforçar conceitos-chave sobre dados, bancos de dados e serviços do Azure.
